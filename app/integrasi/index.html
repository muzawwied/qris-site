API key

Pakai di header Authorization saat memanggil API dari servermu.

memuat…
curl -X POST https://qris-site.pages.dev/api/pay \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  -d '{"amount":150000,"reference":"INV-1024"}'

Jangan menaruh key ini di kode frontend. Simpan di environment server.

Alur singkat

Tiga panggilan, selesai.

  1. POST /api/pay — buat tagihan, dapat qr_image dan checkout_url.
  2. GET /api/pay/{id} — cek status, atau tunggu webhook.
  3. POST /api/webhook — dipanggil provider, status jadi paid.
